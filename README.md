# Веб-сервис "AParts"
Сервис создан при помощи Java и Spring Framework
## Описание
AParts - веб-приложение для управления интернет-магазином автозапчастей, предоставляющее различные возможности для администрирования магазином, управления персоналом и заказами, а также обеспечивающее удобный интерфейс для клиентов для просмотра запчастей и создания заказов.

## Функционал
1. CRUD-операции:
      * Разработан и интегрирован функционал для управления данными приложения, такими как каталог запчастей, сотрудники, пользователи, заказы и другие.
2. Аутентификация и авторизация пользоватлей:
      * Реализована система регистрации и входа в систему с обязательной валидацией данных и конфигурацией Spring Security.
3. Реляционная бд:
      * Организована автоматическое создание нормализованной БД (PostgreSQL).
4. Разделение ролей и безопасность приложения:
      * Внедрено детализированное разделение ролей на администратора, работника, доставщика и пользователей и другие меры безопасности с использованием Spring Security.
5. Корзина и валидация заказов:
      * Разработана корзина для пользователей с валидацией наличия товаров и данных для безопасного оформления заказов.
6. Автоматизация статусов заказов:
      * Разработана система автоматического изменения статусов заказов в реальном времени. Статус заказа автоматически изменяется в процессе работы сотрудников и доставщиков над заказом.
7. История и отслеживание заказов:
      * Организован механизм отслеживания и хранения истории заказов пользователей.
8. Расширенный поиск данных:
      * Внедрены меры для возможности расширенного поиска и фильтрации данных с использованием JPA.
9. Панели управления:
      * Созданы панели управления для работников и разработаны соотвтетствующие энд-поинты.
10. Шаблонизация данных:
      * Для динамической генерации HTML-страниц был использован шаблонизатор Freemarker.
11. Пагинация и визуализация данных:
      * Реализована пагинация при просмотре данных при помощи Spring Web.
12. MVC-паттерн:
      * Архитектура приложения организована в соотвествии с паттерном проектирования Model-View-Controller.
